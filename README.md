# FreshFold

Full laundry platform.

## Structure
- `public/index.html` — Frontend (deploy this on Vercel)
- `backend/` — Node.js + Razorpay server
- `docs/` — Supabase schema & guides

## Deploy Frontend (Vercel)
1. Push this folder to GitHub
2. Import on Vercel
3. Set Root Directory to `public` (or just deploy the public folder)

## Backend
See `backend/server.js` and `docs/razorpay-setup.md`
